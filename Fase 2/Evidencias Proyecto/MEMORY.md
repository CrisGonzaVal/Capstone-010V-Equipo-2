## Aprendizajes y errores a evitar
- Cierre = verificación (AGENTS §8.5–§8.7): los dos puertos; 8080 exige `docker compose build frontend`; el backend recarga solo; grep de coherencia sobre AGENTS/MEMORY/skills al cerrar.
- **Contratos externos:** la API real de Clerk `GET /v1/invitations` devuelve una **lista desnuda**, no `{"data":[…]}`; el fake de tests envolvía la forma y ocultó el 503 del alta con correo nuevo (017). Verificar contra la API real además del transporte simulado.
- **La semilla limpia no crea la identidad de control del Superadmin:** `control.usuario` queda vacía, nadie invoca `ejecutar_bootstrap_control` al arrancar y `superadmin@compustock.cl` no existe en Clerk, así que un clon nuevo no entra a `/control` (017: se ejecutó a mano). Verificar si corresponde a una feature futura.
- Tests PostgreSQL **gated** (`POSTGRES_TEST_URL`); SQLite no valida esquemas/namespaces ni FK compuestas. Bugs que solo salen en PG: sesión de control vs tenant (012) y `DetachedInstanceError` del lector global (013: construir el DTO eager dentro de la sesión de cada tenant). Base desechable para gated; `apt_erp` nunca se toca.
- Al cambiar el esquema o la semilla, actualizar `01_`/`02_` y probar el arranque limpio (`down -v` + `up -d`); no hay migraciones que preservar.
- Tras `02_`, `control.estado_ticket` conserva **solo** la fila `Anulado`, `control.registro_motivo_constancia` queda vacía y las tablas de negocio de `control` quedan sin filas (los datos viven en cada tenant).
- Toda mutación de estado exige actor **persistido** (FK del historial): fixtures con la sonda sintética `9999` deben pasar a un usuario real; si no, el INSERT del historial revienta con `IntegrityError`.
- Edge: fijar `CHROME_BIN` y usar `--watch=false --browsers=ChromeHeadless` (nunca `npm test`). PowerShell: `pg_dump`/restauración con `cmd /c`; `docker exec sh -c` con `$()` y comillas anidadas se rompe; BusyBox `grep` sin `--include` (usar `grep -r`); `curl.exe` conserva backslashes de escape (usar archivos de body). `urllib` contra Clerk necesita `User-Agent` (si no, 403 Cloudflare 1010).
- Clerk por HTTP sin navegador: el FAPI con Basic auth es stateless por request; usar dev browser (`POST /v1/dev_browser`, query `__dev_session`) + sign-in ticket BAPI (`POST /v1/sign_in_tokens`, campo `token`, estrategia `ticket`, form-encoded) + `Origin: localhost:4200` (el backend exige `azp`; sin él → 401). Tokens ~60 s. Aceptar una invitación exige `sign_up` `strategy=ticket` → `PATCH` contraseña → `email_code` `424242`.
- Specs Angular de navegación: con `provideRouter([])` el click de un `routerLink` no actualiza `router.url`; probar «navega a X» con el `href` y un espía a `router.navigateByUrl`.
- psycopg2 2.9+ **no expone `password`** en `get_dsn_parameters()`: reutilizar la URL original cambiando solo el nombre de base.
- `resolver_contexto_solicitud` sin `abrir_sesion_tenant` lee la versión de **control**, no del tenant: el gated debe cablear `abrir_sesion_tenant=crear_sesion_esquema` (espejo de `dependencies.py`).
