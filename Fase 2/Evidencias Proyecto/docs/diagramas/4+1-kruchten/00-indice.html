Lectura del modelo. Las cuatro vistas no son planos independientes: comparten el mismo sistema y se validan entre sí. La vista lógica fija las entidades; la de procesos muestra cómo se coordinan; la de desarrollo explica cómo se empaquetan; y la física confirma dónde viven.

Cada diagrama se genera primero como HTML autocontenido y luego se rasteriza a PNG a 2x. Los tokens visuales (paper #f8fafc, ink #1e293b, accent #2563eb) coinciden con los diagramas de casos de uso del proyecto.
