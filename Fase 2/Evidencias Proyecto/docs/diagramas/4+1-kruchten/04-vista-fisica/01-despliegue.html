Despliegue · Docker Compose en el host local

Nodos de ejecución, contenedores, puertos y volúmenes. El navegador entra por el 8080 de nginx; nginx sirve el build de Angular y proxya /api al backend; el backend habla con PostgreSQL por la red interna y con Clerk por HTTPS. La base publica el 5433 solo para administración local.

Lo que el diagrama evita. El 5433 está publicado, pero no es la vía de la aplicación: el backend entra por db:5432 en la red bridge. El 8080 no habla con el backend por CORS, sino por el proxy de nginx. Y el frontend del contenedor no es el dev server: es un build inmutable, así que una feature no está cerrada hasta reconstruir la imagen.
